# DESIGN (draft baseline)

视觉基线草案,只定方向,不跑完整设计流程。

## 方向

一台还在运行的 1979 年终端。冷、暗、低饱和,信息靠字距与留白分层,不靠卡片和阴影堆叠。
玩家看到的每一行都是「机器打印出来的」,不是网页组件。

## 颜色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 背景 | `#05080a` | 页面底色 |
| 面板 | `#050907` / 92% | 终端主体 |
| 正文 | `#c9f7d4` | 默认文字 |
| 强调 | `#7ef0a6` | 提示符、命令回显、标题 |
| 次级 | `#5f8f72` | 系统提示、状态栏 |
| 错误 | `#ff8a7a` | 被解释器拒绝的输入 |
| 分隔线 | `#12301f` | 边框与分区 |

只允许一个强调色。错误色仅用于拒绝路径,不用于装饰。

## 字体与排版

- 全站等宽:`Cascadia Mono` → `SFMono-Regular` → `Consolas` → `monospace`。
- 正文 `0.95rem / 1.55`;标题栏 `0.75rem`,字距 `0.12em`,全大写。
- 行间距 `0.35rem`,保持终端密度;正文行宽上限约 72 个字符。

## 布局

三段式:标题栏 / 可滚动转写区 / 输入行。桌面居中,最大 `72rem × 44rem`;
窄屏铺满,去掉外边框。

## 动效

只保留两种:新行进入时的即时追加,以及转写区自动滚到底。不做打字机动画,
它会让「状态已改变」和「文字正在出现」混淆。

## 禁止

- 圆角卡片、玻璃拟态、渐变按钮。
- 用颜色表达状态(位置、回合数一律用文字)。
- 在转写区插入图片或图标打断阅读。
