# 0001 状态权威归解释器

- 状态:已确认
- 日期:2026-11-11

## 背景

演示的核心主张是「LLM 说话,Z-machine 持有真相」。若 LLM 能改世界状态,
幻觉就会变成事实,撤销与重放也不再成立。

## 决定

世界状态只由 `src/zmachine/` 产生。LLM 只输出意图(命令或对状态的提问),
不输出状态;UI 只渲染解释器的输出与当前状态。

## 后果

- 新增玩法必须落在解释器里,并配 `fast-check` 性质测试。
- UI 里出现任何 `WorldState` 字面量都视为缺陷。
- 「模型说玩家在走廊」不构成事实,以 `machine.state.location` 为准。

## 被否选项

- 让 LLM 维护对话内的世界状态:无法防幻觉,无法重放,直接否定演示主张。
- 解释器与 LLM 双写状态并以最后写入为准:两个真相源,冲突时不可解释。
