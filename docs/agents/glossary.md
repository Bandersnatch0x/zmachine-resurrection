# 术语表

本仓领域词汇的唯一权威。工程技能产出的票标题、规格、测试名一律用这里的词。

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 状态权威 | state authority | 唯一被允许产生游戏事实的组件;本仓固定为解释器。 |
| 解释器 | interpreter | 实现 Z-machine 指令语义的确定性核心,位于 `src/zmachine/`。 |
| 前端 | front end | 把玩家自然语言转成意图的层;不得写世界状态。 |
| 回合 | turn | 一次输入到一次输出的完整处理,产出新状态与转写行。 |
| 快照 | snapshot | 某一回合结束时的完整 `WorldState`;用于撤销与重放。 |
| 确定性重放 | deterministic replay | 同一快照 + 同一命令序列必得同一状态与输出。 |
| 转写行 | transcript line | 玩家可见的一行输出,须可追溯到某个回合或显式的界面提示。 |

## 禁用近义

- 用「回合」,不用「step」「tick」描述玩家可见的处理单位。
- 用「状态权威」,不用「source of truth」等泛称指代本仓的边界。
