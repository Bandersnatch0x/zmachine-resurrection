# 领域文档消费规则

工程类技能在本仓探索、产文时的领域文档读取约定。

## 探索前先读

- `docs/agents/glossary.md` — 术语表(词汇唯一权威)。
- 已确认裁决:`docs/agents/decisions/`。

若目标仓不设 ADR 目录,决策记录一律在票内。任一上述落点缺失时静默继续,不主动补建。

## 用术语表词汇

产出(票标题、规格、重构提案、假设、测试名)命名领域概念时,用术语表定义的术语;不漂向术语表明示规避的近义词。

要用的概念尚不在术语表 → 先重新考虑措辞;确属缺口,记入拷问阶段的术语沉淀。

## 与已确认裁决冲突时

产出与既有已确认裁决相悖,不得静默推翻,显式标出相悖点与理由,交用户裁。
