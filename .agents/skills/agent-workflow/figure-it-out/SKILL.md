# Figure It Out

## When to use

- The work spans phases, repositories, actors, or several independent risks.
- A human will review the result after a long or unattended run.
- The goal is clear but the execution path and evidence plan are not.

## How to use

1. Frame the outcome, constraints, unknowns, budget, stop condition, and irreversible boundaries.
2. Break the work into verifiable units with owners, write sets, dependencies, and acceptance evidence.
3. Run the highest-risk experiment or slice first. Keep a decision trail and update it after each unit.
4. Re-plan when evidence breaks an assumption. Do not preserve a plan that no longer fits the system.
5. Close with the actual result, unverified areas, rollback path, and the next safe handoff.

## Boundaries

- Do not use this as a larger name for a simple task.
- Do not let a plan become a second specification or task authority.
- Do not continue past a stop condition merely because work remains in the queue.
